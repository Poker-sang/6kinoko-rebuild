## 证据与范围

本目录保存 IDA MCP 的反编译、交叉引用及混合函数反汇编。
E-imports 与 EXE SHA256 沿用同一原版的
`../act-update-20260919/ida-survey.json`、`ida-imports*.json`；
451640 的关键汇编在该目录的 `ida-update-asm.json`。
42AC20 的 Hex-Rays 请求导致 worker 不可达，按技能脚本重开原版，改用反汇编；
失败回包保留，没有把失败的伪代码当作证据。

Squirrel 回调仍通过既有 `function_415810_this` 桥进入源码 VM，没有重写 VM
或删除 trace 调用；上批已核对提供的 Squirrel 2.2.2 CallNative 源码/反汇编，
本批未改变该接口及其外部引用所有权。

保留兼容范围：原版 inactive/editor 分支、离屏渲染目标、Suspend/Resume 的
资源虚调用以及 STL 分配策略尚未在本批完整恢复。额外查询这些相邻函数只是
确定边界，不能计入已迁移数量。游戏运行正常也不能作为这些差异无影响的证明。
