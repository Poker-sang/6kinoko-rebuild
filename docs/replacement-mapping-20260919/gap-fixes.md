# 两项实现缺口修复（2026-09-20）

实现及测试源码提交：`710e0de`。原版依据保留在
`analysis/remaining-mapping-20260920/`：40A8D0、4A8D60、4D4B30 和
49C350 的 IDA 输出，以及提供的 Squirrel 2.2.2 源码/对象反汇编证据。

## 修复

- **PauseBgm / 40A8D0**：470300 改用独立暂停切换函数，在音频锁内查询
  DirectSound 状态；播放中 Stop，停止时 Play(DSBPLAY_LOOPING)。不调用
  SetCurrentPosition，不清除流游标或已缓冲字节数。原 StopBgm 保持归零行为。
- **共享状态链 / 4A8D60、4D4B30**：宿主第一次挂入拥有的状态时注册 CRT
  退出清理。先销毁当前节点的 SQSharedState，再递归清理后继节点，最后释放
  节点并清空链头。状态析构直接使用提供的源码，不借用会额外 Finalize 的
  sq_close。普通 4A8C50 仍只清理宿主包装对象，传入的外部 VM 不进入拥有链。
