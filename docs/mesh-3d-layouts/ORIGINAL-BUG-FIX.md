# ⚠ 原版缺陷修正：Mesh 根节点编号被误作模型指针

**这是明确偏离原版错误行为的修正，不是反编译命名整理。**

2026-09-22 用户明确授权：“醒目标记一下，然后修复，然后继续推进”。
此前关于是否允许修正的确认已经结束，不应再次请求相同授权。

原版 `44CA41` 从控制器根节点 `+20` 读取值，并在 `44CA49` 传给模型树
遍历器 `44CA60`。但 `457280` 证明 `+20` 是整数注册编号，`457310` 证明
真正的模型指针在 `+24`。空模型根节点编号为 0；含子节点时编号通常是
更大的整数。把它作为对象地址会导致无效访问。

新实现 `act_mesh.cpp::load_resource` 使用具名字段 `state.root->model`，
不再把 `registry_index` 转成指针。代码调用点包含醒目的
`ORIGINAL BUG FIX` 注释，并指向本记录。

只修复这一处错误。以下原版行为保留：

- `44C990` 在加载分支末尾仍返回 false，不把已生成节点等同于返回 true。
- Mesh 名称用于打开模型文件，prefix 用于引用模型及材质路径。
- ACT 的绘制记录通过 SetMesh 绑定，不额外附加控制器矩阵或自动动画。
- 3D 布局矩阵顺序为旋转、平移、缩放；资源 Query 失败的提前返回不恢复
  已改变的渲染状态。
- 3D 序列化 trans/roll 字段别名、脚本属性 `coS_z` 以及绘制收尾三角形
  均按原版证据保留，没有顺手改成推测的设计意图。

原版证据是静态反汇编，**没有运行复现**。本记录不证明原游戏资源实际
引用 Mesh，也不把“2D 游戏”当作没有 3D 引用的证据。
