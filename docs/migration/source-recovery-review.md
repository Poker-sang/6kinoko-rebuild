# 分析一：源码级 C++ 恢复工作量与收尾评审

这是 2026-09-24 对话中第一次分析的仓库化记录，保留结论、数值、假设和限制，
不是对本 PR 的新完成率认证。评审基线为 `08247b5431ff6d2459a6affe58c24f51ac90c573`。
原分析是只读审计，未运行游戏或本地测试。本次修改情况另见 [HANDOFF](HANDOFF.md)。

## 结论

项目已进入恢复后半程，但不是只剩改名和整理目录。可以开始模块级收尾；全局收尾之前，
需要防漏检审计以及类型、所有权、关键失败路径的验收。后续以“关闭完整业务生命周期”
而非“消灭 function_xxx 数量”为目标。不要把包装后的函数或具名的固定偏移代码当作恢复完成。

范围只有顶层 CMake 直接列出的 156 个 src 文件，不含头文件、上游实现、测试等。
“未检出”不意味着真实为零，1,935 也不是 AST 解析确认的项目函数总数。

当时确认的两个缺陷：

- `KinokoActorPool *kinoko_actor_pool_construct(...)` 和 `KinokoActor *kinoko_actor_pool_acquire(...)`
  这类星号紧贴函数名的签名会漏检；构造析构、宏、复杂声明也没有完整语法覆盖。
- [ACT 图层构造](../../src/reconstructed/act_document.cpp) 的 `field<T>(layer + 数字)`、
  348 字节分配和嵌入对象偏移可能仍被分入结构化候选。分类器主要识别地址函数名、v/g 数字变量、

因此不能宣布“85.6% 已完全恢复”。兼容入口是否必要，也必须依据真实调用者判断，不能由名称决定。
本 PR 保留历史清单不覆盖；完整 census 纠偏仍在待办。

## 已有实质成果与剩余债务

[act_mesh](../../src/reconstructed/act_mesh.cpp) 已经有 unique/shared/weak 所有权与 ComOwner；
[RecordView](../../include/kinoko/native_record_view.hpp) 用具名布局成员和 memcpy 访问字节记录，
不是把旧内存伪装成已构造的 C++ 对象。这些恢复成果可以保留。

主要剩余债务是：ACT 字段恢复不完整；内部整数指针往返；创建、加载、发布、克隆、复用、
销毁和半初始化失败状态之间的所有权验收。列为验收重点不等于已经证明其中有错误。
本 PR 只消除了 Actor 池的一部分内部指针往返，不代表整条生命周期已经验收。

普通 T*、借用指针、必要虚调用和真实文件格式常量不是问题。不要为消除星号或数字而引入包装，
也不能给未知字段杜撰含义。必要的 Win32／文件布局适配应集中在清楚的边界。

## P0–P3 工作目标

| 优先级 | 目标 | 验收标准 | 初步预算 |
|---|---|---|---:|
| P0 | 固定提交、完善统计及人工债务台账 | 已知签名不再漏检，隐藏偏移进入债务项，兼容入口有依据 | 2–4 人日 |
| P1 | ACT 文档／图层／资源 → Actor 池 → 脚本交接的完整生命周期 | 类型一致、拥有／借用明确、失败回滚和原版证据闭合 | 10–20 人日 |
| P2 | 缩小兼容边界、整理模块 | 维护业务逻辑不必了解 RetDec 整数槽；必要 ABI 有调用者证明 | 8–16 人日 |
| P3 | 回归证据、允许差异说明、全局收口 | 源码／产物／验证主体一一对应，不以构建代替运行 | 10–20 人日 |

建议台账分类：A 已验收源码实现；B 已验收必要兼容边界；C 已具名但有语义债务；
D 仍依赖反编译表达；E 未审查／证据不足。只有 A/B 不阻碍对应模块收尾。
覆盖头文件实现、构造析构、实际编译配置；入口和目标实现建立映射，不把几个转发壳当几份进度。

30–60 人日约为 6–12 个五工作日人周，是**中低置信度工程预算**，不是测得工时或交付日期。
假设一名熟悉代码和原版证据的工程师，只做 Win32 保真恢复，没有加入 x64、跨平台、mod 和编辑器。
P0 后应按真实 C/D/E 债务复杂度重估；不要把这笔预算扩展解释成现代化项目总工期。

## 收尾条件

现在可对 A/B 类模块逐个冻结接口并补文档，减少反复的装饰性重构。
P0 完成、核心生命周期闭合、关键行为无猜测／空成功替代、兼容层不再向业务扩散、
验证责任清楚后，进入全局只处理阻断项的收尾。

最终标准：生产可达业务实现归入 A，必要边界归入 B，已知行为差异有解释和明确处置，
交付源码与验证记录一致。允许保留原版证据、填充字节、必要借用和布局视图。
function_xxx 清零、扩展名全是 cpp、词法报表全绿或 CI 通过，都不能单独作为结束条件。

下一批应优先“统计纠偏＋ACT 图层完整类型”，然后关闭 Actor 池／所有权链路；
已经验收的模块同时收尾。现代化规划见 [第二份分析](modernization-strategy.md)。
